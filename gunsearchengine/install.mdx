GunSearchEngine records what shoppers typed into your site search, including searches that returned nothing. Install is a script on the WooCommerce store. The product and the dealer dashboard live on GunSearchEngine. This page does not sell the product. It places the tag.

## Install

1. Get the script snippet from the GunSearchEngine dealer screen, or from Coriolis if we are placing it for you.
2. The snippet goes in the site header, once. On Kadence that is a header script hook, not a paste into a page.
3. Publish and load the homepage in a private window. Search for a caliber you know you stock, then search for a nonsense string.
4. In [FFL Analytics](https://www.gunsearchengine.com/for-dealers/ffl-analytics) in the GunSearchEngine.com Dealer Dashboard, confirm both queries arrived. Observe mode means the script records and does not change your search results.
5. Do not install a second copy in a tag manager and in the theme. Duplicate tags double-count.

## How to read the first week

Empty searches are the useful row. A caliber or model that returns nothing is either missing from the catalog or named differently than the buyer types. Fix the product title or import the SKU. Do not treat a single search as a buying signal.

The product is on [GunSearchEngine.com](https://www.gunsearchengine.com/). For demand views beyond this install, see [Demand Intelligence](https://www.gunsearchengine.com/demand-intelligence).
